# 네이버 블로그 자동 글쓰기 🐾

폰에서 사진이랑 정보만 올리면, 맥에서 Claude Code가 사진을 전부 보고
**네이버 블로그용 후기 HTML + 올릴 사진 순서 폴더**를 만들어주는 시스템이에요.

---

## 🆕 새 맥 / 새 계정에서 처음 시작할 때

### 1. 한 줄로 설치하기

터미널을 열고 이 한 줄만 붙여넣으세요.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/emily1818/naver-blog-auto/main/install.sh)"
```

없는 것만 알아서 설치해요 (개발도구 → Homebrew → cloudflared),
코드를 `~/claude/naver-blog-auto` 에 받고, 업로더까지 켜줘요.
중간에 설치 창이 뜨면 [설치], 비밀번호를 물으면 맥 로그인 비밀번호를 넣으면 돼요.

### 2. 다음부터 켜기

Finder에서 `naver-blog-auto` 폴더를 열고 **`시작하기.command`** 를 더블클릭하세요.

처음 누르면 업로더에 쓸 **아이디/비밀번호를 물어봐요.**
아무거나 정하시면 되고, `auth.local` 에 저장돼서 다음부터는 안 물어봐요.
(이 파일은 git에 안 올라가요)

> ⚠️ `.command` 파일이 "열 수 없음"이라고 뜨면
> 파일을 **우클릭 → 열기** 로 한 번만 열어주세요. 그 다음부터는 더블클릭돼요.
>
> 그래도 안 되면 터미널에 한 번만:
> ```bash
> chmod +x ~/claude/naver-blog-auto/*.command
> ```

## 📱 평소 쓰는 법

### 1) 켜기
`시작하기.command` 더블클릭 → **접속 주소**가 나오고 클립보드에 복사돼요.
그 주소를 폰으로 보내서 열면 업로더가 떠요.

| 업로더 | 쓰는 곳 |
|---|---|
| 🍚 맛집 | 식당·카페 체험단 후기 |
| ✈️ 여행 | 여행지·관광지·여행정보 |

> 주소는 **켤 때마다 바뀌어요.** 다시 확인하려면 `현재주소_확인.command` 를 누르세요.

### 2) 폰에서 올리기
업로더 화면에서 **지역 / 가게 / 요청사항**을 적고 사진을 올리면
맥의 `inbox/` 폴더에 자동으로 저장돼요.

`요청사항`에는 **업체가 준 요구사항**이랑 **직접 먹어본 느낌**을 같이 적어주세요.
글의 재료가 되는 부분이라 자세할수록 좋아요.

### 3) 맥에서 글 만들기
Claude Code를 열고 이렇게 말하면 돼요.

> **"새글 왔어"** 또는 **"새글 작성해줘"**

그러면 Claude가:
1. `inbox/` 에서 안 쓴 폴더를 찾아 `meta.txt` 를 읽고
2. 사진을 **전부** 확인해요 (메뉴판은 확대해서 가격까지 읽어요)
3. `posts/<가게이름>_최종.html` 을 만들고
4. `올릴순서_<가게이름>/` 에 사진을 `01_설명.jpg` 순서로 정리해주고
5. 완성된 HTML 파일을 바로 건네줘요

### 4) 네이버에 올리기
받은 HTML을 열어서 **본문 전체 복사 → 네이버 블로그 붙여넣기**,
그 다음 `【 📷 01번 】` 자리에 폴더의 사진을 순서대로 넣으면 끝이에요.

### 5) 끄기
`끄기.command` 더블클릭.

## 📂 폴더 구조

```
naver-blog-auto/
├── 시작하기.command        ← 더블클릭해서 켜기
├── 끄기.command            ← 더블클릭해서 끄기
├── 현재주소_확인.command    ← 접속 주소 다시 보기
├── install.sh              ← 새 맥 한 줄 설치
│
├── uploader.py             맛집 업로더 (포트 8765)
├── uploader_travel.py      여행 업로더 (포트 8766)
│
├── STYLE.md                ★ 글 쓰는 규칙 (말투·제목·사진·SEO)
├── TISTORY.md              ★ 티스토리판 만드는 법
├── 형식_템플릿.html         ★ 글 HTML 형식 견본
│
├── tools/                  티스토리 사진 업로드 도구
│
├── inbox/        (git 제외) 폰에서 올라온 사진이 쌓이는 곳
├── posts/        (git 제외) 완성된 글
└── 올릴순서_*/    (git 제외) 네이버에 올릴 사진 순서 폴더
```

> **사진은 git에 안 올라가요.** 이 레포는 public이라서 `inbox/`, `posts/`,
> `올릴순서_*/` 는 전부 `.gitignore` 로 막아뒀어요.
> 새 맥에서 clone 하면 **코드랑 규칙만** 받아지고, 사진은 안 따라와요.

---

## 🔑 계정이 바뀌어도 되나요?

네, 괜찮아요. 이 레포에는 **비밀번호가 하나도 안 들어있어요.**

| 항목 | 어디에 있나 | 새 맥에서 |
|---|---|---|
| 업로더 아이디/비번 | `auth.local` (git 제외) | 처음 켤 때 새로 정하면 돼요 |
| 접속 주소(터널) | 켤 때마다 자동 발급 | 신경 안 써도 돼요 |
| 네이버·티스토리 로그인 | 브라우저에서 직접 | 평소처럼 로그인하면 돼요 |

그래서 **clone → `시작하기.command` 더블클릭**, 이 두 단계면 끝이에요.

---

## 🩹 안 될 때

| 증상 | 해결 |
|---|---|
| 폰에서 주소가 안 열려요 | `시작하기.command` 를 다시 눌러주세요. 주소가 새로 나와요 |
| 주소는 나오는데 안 들어가져요 | 맥이 잠자기 모드인지 확인해주세요. 꺼지면 터널도 끊겨요 |
| `.command` 가 안 열려요 | 우클릭 → 열기, 또는 `chmod +x *.command` |
| flask 없다고 떠요 | `python3 -m pip install --user flask` |
| 사진이 안 올라가요 | `끄기.command` → `시작하기.command` 순서로 다시 켜주세요 |
